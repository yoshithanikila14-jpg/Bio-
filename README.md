# 🎓 Apex Tuition - 3D Educational Web Platform

A 3D educational web platform created for G.C.E. Advanced Level (A/L) students in Sri Lanka, based on the reference design.

---

## 🚀 Running on Localhost

The server is already running in the background!
You can open it right away in your browser at:
👉 **[http://localhost:3000](http://localhost:3000)**

If you ever need to restart the server manually:
```bash
npm start
# or
node server.js
```

---

## ✨ Features Included

### 1. 🎯 Pixel-Perfect 3D Hero Section (Exact Match to Reference Image)
- **1:1 Exact 3D Master Mode**: High-resolution 2K 3D graphics rendered with interactive clickable hotspots and hover glows.
- **Dynamic CSS Mode**: Pure DOM version with 3D claymorphic text, extruded yellow burst rays, and animated floating 3D character.
- **Interactive Top Navbar**:
  - 🎓 Logo: **Apex Tuition**
  - Links: `Home`, `Courses ▾`, `About`, `Resources ▾`, `Contact`
  - 🔍 Quick Search button with live autocomplete modal
  - `Join Now →` button with student registration modal
- **Hero Left Side**:
  - 🏆 `A/L Success Starts Here!` glassmorphic capsule badge
  - Big 3D extruded clay typography: **Apex** (pure white) + **Tuition** (warm amber with burst rays)
  - `Learn • Practice • Excel`
  - Body text: *Smart study plans, expert guidance and everything you need to ace your A/Ls!*
  - CTA Buttons: `Start Learning` (with coin/medal) & `Explore Courses →`
- **Hero Right Side 3D World**:
  - 3D Student Boy clutching royal blue "A/L" textbook, pointing enthusiastically towards the headline
  - Orbiting 3D atom model
  - Glowing chemistry beaker with bubbles
  - Translucent blue DNA double-helix spiral
  - Open notebook, stacked books, and colored pencils cup
  - Interactive mousemove 3D perspective tilt & parallax physics!
- **4 Bottom Docked Feature Cards**:
  1. 📅 **Smart Timetable** - *Plan Your Study* (Opens interactive weekly schedule)
  2. 🎯 **Revision Hub** - *Revise Smarter* (Opens past papers & model papers hub)
  3. 📊 **Better Results** - *Reach Higher* (Opens island rankers leaderboard)
  4. 🎧 **24/7 Support** - *Always With You* (Opens live student support chat simulation)

### 2. ⚡ Live Revision Countdown Strip
- Real-time countdown timer for the upcoming A/L Grand Revision lecture.

### 3. 📚 A/L Streams & Course Catalog
- Filter by: `All Streams`, `Physical Science (Maths)`, `Biological Science`, `Technology Stream`, `Commerce Stream`.
- Subject cards: Combined Maths, Physics Masterclass, Biology Resource Hub, Chemistry Made Simple, A/L ICT, Accounting & Econ.

### 4. 🧮 UGC Target Faculty & Z-Score Estimator
- Interactive calculator where students select their Stream, District, and Target Faculty to get an estimated cutoff Z-Score.

### 5. 🏆 Island Rankers Leaderboard & Testimonials
- Real student success stories from top rankers across Sri Lanka.

### 6. 💬 24/7 Live Chat Support
- Interactive chat simulation with answers for fees, tutes, and class types.
